# 요약 스타일

제출용 산출물이 아니라 내용 파악용 요약을 작성할 때 적용한다. 결과물은 상위 항목만 읽어도 전체 흐름을 파악할 수 있고 하위 항목은 필요할 때만 읽는 2계층 구조여야 한다.

document-style 스킬을 상위 규칙으로 하되, 명제화·계층화는 완결 문장 규범의 예외로 적용한다.

## 선별: 특이성 없는 정보의 삭제

- 통계적 근거 없이도 누구나 유추할 수 있는 일반론("수요가 증가한다", "필요성이 확대된다" 등)은 서술할 가치가 없으므로 삭제한다.
- 요약 대상과 무관한 열거는 삭제한다. 과제·제품으로 이어지는 논리가 없는 항목은 배경 서술이라도 제거한다.
- 제목만 다르고 내용의 경계가 없는 절은 하나로 병합한다.
- 고유 정보(수치, 고유명사, 검증 가능한 사실)는 남기되, 절대값의 나열보다 비율·방향처럼 판단에 쓰이는 형태로 옮긴다.

## 명제화: 관계의 기호 표기

- 서술어와 어미를 생략하고, 사실 사이의 관계는 기호로 표기한다.
  - `↑` / `↓`: 증가·확대 / 감소·축소를 나타낸다. 증가, 확대, 급증처럼 서로 다른 어휘를 하나의 기호로 통일한다.
  - `∴`: 인과 관계를 나타낸다. 좌변이 원인이고 우변이 결과이다.
  - `→`: 전환·이동·귀결을 나타낸다.
    - (예) "반려동물 양육 가구 증가에 따라 건강·행동·생활환경의 체계적 관리 수요가 확대" → "반려동물 양육 가구 ↑ ∴ 체계적인 케어 수요 ↑"
- 좌우 대칭 형태(`A ↑ ∴ B ↑`)를 유지하면 항목을 나열했을 때 원인과 결과를 서로 비교하기 쉽다.

## 그룹핑: 열거의 상위어 통합

- 여러 항목의 나열은 이해하기 쉬운 상위어 하나로 묶는다.
  - (예) 활동·수면·식사 → 생활 데이터
- 상위어의 작명과 재사용은 상위 규칙의 용어 조항을 따르므로, 재사용하지 않을 용어는 만들지 않는다.
- 상위어는 서너 개를 넘기지 않는다. 수가 많으면 기억 부담이 압축의 이득을 넘어선다.

## 계층화: 세부의 하위 이동

- 그룹핑으로 묶은 세부는 삭제하지 않고 하위 항목으로 내린다. 독자는 상위 항목만으로 흐름을 파악하고, 하위 항목은 필요할 때만 읽는다.
- 하위 항목의 정의는 뜻의 되풀이가 아니라 경계의 확정이어야 하므로, 무엇이 포함되고 무엇이 제외되는지를 밝힌다.
  - (부적절한 예) "생활 데이터: 생활과 관련된 신호를 수집한 데이터"
  - (적절한 예) "생활 데이터: 활동, 수면, 식사 등 행동의 기록. 심박·호흡 등 생체 신호는 제외"

## 함의 제거: 용어가 함의하는 수식의 삭제

- 널리 통용되는 용어가 이미 함의하는 수식은 삭제한다.
  - (예) "센서·카메라 기반 홈 IoT" → "홈 IoT"
- 삭제한 세부가 문서의 다른 지점에서 중요해지면(예: 측정 수단이 차별점인 절), 그 지점에서 서술한다.
